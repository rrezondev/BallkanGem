# Kosova Tourist Guide Web App

## Përshkrimi
Aplikacioni web "Kosova Tourist Guide" është një platformë që ofron informacione turistike për Kosovën. Aplikacioni përmban informacione për destinacionet kryesore, hotelet, restorantet dhe gjeneron itinerare të personalizuara për turistët.

## Veçoritë
1. **Kryefaqja interaktive** me slider të imazheve
2. **Seksioni i destinacioneve** me të dhëna të hollësishme
3. **Informacione për hotelet** me çmime dhe rating
4. **Guida e restoranteve** me lloje të ndryshme të kuzhinës
5. **Gjenerues i itinerareve** të personalizuara
6. **Forma e kontaktit** për komunikim
7. **Design responsive** për të gjitha pajisjet

## Teknologjitë e përdorura
- HTML5
- CSS3 (me variabla dhe grid)
- JavaScript (vanilla)
- Font Awesome për ikona
- Google Fonts për tipografi

## Si të ekzekutoni
1. Shkarkoni të gjitha skedarët në një dosje
2. Hapni skedarin `index.html` në shfletuesin tuaj
3. Aplikacioni është gati për përdorim

## Struktura e skedarëve
- `index.html` - Struktura kryesore
- `style.css` - Stilet dhe design-i
- `script.js` - Funksionaliteti JavaScript
- `data.js` - Të dhënat e aplikacionit

## Funksionalitete të ardhshme
1. Integrimi me Google Maps
2. Sistem rezervimesh online
3. Komente dhe rating nga përdoruesit
4. Versioni mobile app
5. Sistem paguash online
6. Blog për udhërrëfye

## Autor
Ky projekt është krijuar si detyrë fakulteti për udhërrëfyesin turistik të Kosovës.
